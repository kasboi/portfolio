BanffPay is a global payments platform that simplifies international money transfers and currency exchange. I built their corporate website using Astro for optimal performance and SEO.

## Features

- Multi-page corporate website with smooth navigation
- Responsive design for all devices
- GSAP animations for engaging user experience
- SEO optimized with Astro's static site generation
- Service showcase: Send Money, Exchange Currencies, Fund Accounts, B-Now
- Multi-country support (Canada, Nigeria, Ghana, Liberia, Angola)
