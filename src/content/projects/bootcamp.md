A comprehensive learning platform for the Career Connects Frontend Bootcamp. Built with Astro Starlight, this documentation site serves as the central hub for bootcamp participants.

## Features

- Complete curriculum for HTML, CSS, JavaScript, and React
- Interactive code examples with live output previews
- Multiple choice questions and practical coding exercises
- Structured learning path from basics to advanced concepts
- MDX support for rich, interactive content
- Responsive design with dark/light theme support
- Navigation sidebar with topic organization
